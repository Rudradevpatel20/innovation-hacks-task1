# Innovation Hacks – Task 1
## Developer Productivity Dashboard

A responsive Developer Productivity Dashboard built using React.js as part of the Innovation Hacks Full Stack Development Internship.

## Features

- Dashboard / home page
- Navigation bar
- User / profile section
- Project and task cards
- Task and project progress indicators
- Search and filter functionality
- Responsive design for desktop, tablet, and mobile
- Loading and empty states
- Reusable React components

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3

## Installation

1. Clone the repository.
2. Open the `frontend` directory.
3. Install dependencies:

npm install

4. Start the development server:

npm start
